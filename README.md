# 경기도는 정말 "부도" 상태인가

경기도 재정을 두고 "부도", "재정위기"라는 표현이 오갔다. 이 저장소는 그 주장을
**법정 판정기준에 실제 수치를 대입해** 확인하려는 시도다. 인상이나 논평이 아니라,
행정안전부가 공표하는 원자료에 기준을 그대로 적용했을 때 무엇이 나오는지를 본다.

결론을 미리 적어두면 — **현재까지 확인한 두 지표에서 경기도 본청은 어떤 임계선에도
닿지 않는다.** 다만 아래 "미확인 항목"에 적은 대로, 이것만으로 법정 판정을
종결할 수는 없다.

## 목적

지방재정법 시행령은 재정진단·재정위기·긴급재정관리단체 지정 요건을 지표와 수치로
규정한다. 이 저장소가 하려는 일은 단순하다.

1. 해당 지표들의 원자료를 행정안전부 지방재정365 OpenAPI에서 수집한다
2. 17개 광역시도 본청을 동일 기준으로 나란히 놓는다
3. 법정 임계값을 대입해 경기도가 어디에 위치하는지 확인한다

비교 대상을 17개 시도 전체로 둔 이유는, 단일 지자체의 절대 수치만으로는
"높다/낮다"를 판단할 수 없기 때문이다.

## 현재까지 확인된 것

### 지표 1. 예산대비채무비율 (2009~2024)

전체 예산 대비 채무잔액의 비율. 값이 클수록 채무 부담이 크다.

| 항목 | 값 |
|---|---|
| 경기 본청 2024 | **11.95%** |
| 17개 시도 본청 2024 평균 / 중앙값 | 14.38% / 13.51% |
| 경기 2024 순위 (높은 쪽이 1위) | **11위 / 17** |
| 경기 16년 최고 / 최저 | 20.13% (2013) / **4.53% (2020)** |
| 본청 전체 16년 범위 | 4.53% ~ 38.63% |

경기의 2020년 4.53%는 **269개 본청-연도 관측치 전체에서 가장 낮은 값**이다.
16년 중 경기가 17개 시도 평균을 웃돈 해는 2013·2014·2015 세 해뿐이다.

추세는 단조롭지 않다. 2013년 20.13%(5위)에서 2020년 4.53%(17위, 최하위)까지
내려갔다가 2024년 11.95%(11위)로 되돌아온 U자형이다. 다만 같은 기간 17개 시도
평균도 22.07%(2011)에서 11.77%(2020)로 함께 떨어졌으므로, **순위 변동을 곧바로
재정 악화·개선으로 읽으면 안 된다.**

### 지표 2. 통합재정수지비율[결산] (2016~2024)

순수한 수입과 지출의 차이. **음수가 적자이며, 음수 자체는 비정상이 아니다.**

| 항목 | 값 |
|---|---|
| 경기 본청 2024 | **−2.35%** |
| 경기 9년 최고 / 최저 | **+15.96% (2016)** / −5.25% (2022) |
| 경기 적자(음수) 연도 | 9년 중 6년 |
| 본청 전체 9년 범위 | −9.56% (세종 2023) ~ +15.96% (경기 2016) |

경기의 2016년 +15.96%는 **153개 본청-연도 관측치 전체에서 가장 높은 값**이다.
2016~2018 흑자에서 2019년 이후 적자가 고착된 형태다.

적자 자체는 경기만의 현상이 아니다. 17개 시도 본청 중 적자 단체 수는
2016년 3곳에서 **2020년 15곳, 2023년 16곳**으로 늘었다. 코로나(2020)와
세수 결손(2023)이 전국 공통으로 나타난다.

### 임계선 대입 결과

통상 거론되는 절대값 25%(재정진단) / 30%(재정위기) 선을 통합재정수지비율에
대입하면:

| 기준 | 본청 | 전체(기초 포함) |
|---|---|---|
| \|값\| > 25% | **0건** | 27건 |
| \|값\| > 30% | **0건** | 9건 |

본청은 하나도 걸리지 않는다. 그리고 **초과 27건은 전부 양수, 즉 흑자다.**
전체 2,187행의 최소값이 −18.32%라 **적자 방향으로 25%를 넘는 사례는 하나도 없다.**
절대값 기준을 쓰면 재정이 좋은 쪽이 "위기"로 잡히므로, 건전성 판정에는
음수 방향 임계(값 < −25%)로 봐야 하며 그 기준으로는 전 관측치 0건이다.

## 미확인 항목

아래는 **아직 확인하지 않았다.** 위 결과만으로 결론을 확정하지 않는 이유다.

- **법정 임계 수치를 조문 원문과 대조하지 않았다.** 25%/30%는 통용되는 수치로
  대입한 것이고, 시행령 제65조의2·제65조의3의 실제 기준값과 산정방식
  (대상회계, 총계/순계)을 원문에서 확인해야 한다.
- **재정위기단체 지정은 단일 지표로 결정되지 않는다.** 여러 지표의 복합 판단과
  절차가 따르며, 이 저장소가 본 것은 그중 2개뿐이다.
- **당초예산 대비 최종예산 증감(감액 추경 빈도)** — 명세만 확인, 미수집
  (`ARBGT`/`ACEXBG`, 2012~2026).
- **세입 예산 대비 결산의 추계 오차** — 명세만 확인, 미수집 (`IIBBH`, 2009~2024).
- **세목별 지방세, 특히 취득세 시도별 추이** — 명세만 확인, 미수집
  (`KAAAE`, 2010~2024).
- **`HEDFC`의 최종예산액이 세입 기준인지 세출 기준인지** 명세에 없다.
  당초예산과 짝지어 증감률을 낼 때 영향을 준다.
- **예산대비채무비율 `0.0` 값이 전체의 42.7%(1,665행)** 를 차지한다.
  무채무인지 미보고인지 구분하지 않았다. 원본 XML의 `pfa_amt1`(채무잔액)과
  `pfa_amt2`(최종예산액)를 대조하면 판별 가능하다. 본청에는 0값이 없으므로
  위 결론에는 영향이 없다.

## 데이터 출처와 재현 방법

**출처:** 행정안전부 지방재정365 (https://www.lofin365.go.kr) OpenAPI.
공공데이터포털 목록은 API 유형이 `LINK`라 실제 호출은 lofin365로 간다.
엔드포인트·파라미터 명세는 [CLAUDE.md](CLAUDE.md)의 대응표 참조.

이용조건: 출처표시, 상업적·비상업적 이용 가능, 2차적 저작물 작성 가능.

### 재현

인증키는 지방재정365 OpenAPI 탭의 "인증키 신청"에서 발급받는다.

```bash
echo "DATA_GO_KR_KEY=발급받은키" > .env
```

```bash
.venv/Scripts/python.exe src/fetch_test.py
```

단건 호출로 키와 응답을 확인한 뒤, 전체 수집을 돌린다.

```bash
.venv/Scripts/python.exe src/collect.py
```

```bash
.venv/Scripts/python.exe src/collect_balance.py
```

두 스크립트 모두 **이미 저장된 원본이 있으면 재호출하지 않으므로** 중단 후
재실행해도 이어서 진행된다. 호출 사이 0.5초 간격을 둔다.

| 스크립트 | 호출 수 | 산출물 |
|---|---|---|
| `src/collect.py` | 272 (16년 × 17시도) | `data/processed/budget_debt_ratio.csv` (3,895행) |
| `src/collect_balance.py` | 153 (9년 × 17시도) | `data/processed/consolidated_balance_ratio.csv` (2,187행) |

원본 XML은 `data/raw/`에 가공 없이 보관된다(gitignore 대상). CSV는 행을 버리지 않고
전부 담되 `본청여부` 컬럼(Y/N)으로 광역 본청과 기초자치단체를 구분한다.

## 한계

- **확정 데이터는 2024년까지다.** 예산 계열 데이터셋에는 2025~2026 값이 있으나
  이는 편성치이므로 결산 확정치와 같은 층으로 비교할 수 없다.
- **연간 지표만 제공된다. 분기 단위 판단은 불가능하다.** 재정 상황이 연중
  어떻게 움직였는지는 이 자료로 알 수 없다.
- **지표 간 산정기준이 다르다.** 예산대비채무비율은 예산·총계, 통합재정수지비율은
  결산 기준이며 시도 평균은 순계다. 지방세 세목 자료(`KAAAE`)는 순계·일반회계다.
  **서로 다른 산정기준의 값을 같은 표에 놓으면 안 된다.**
- **세종은 2012년 출범**이라 2009~2011 데이터가 존재하지 않는다. 이 3년의
  비교 모집단은 17개가 아니라 16개다.
- 이 저장소는 광역 **본청** 비교에 초점을 둔다. 기초자치단체는 수집·보존하지만
  분석 대상으로 삼지 않았다.
